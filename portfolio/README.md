# Portfolio

A clean, single-page developer portfolio. Dark/light theme, smooth scroll navigation, fully responsive.

## Files

| File | Purpose |
|------|---------|
| `index.html` | All content + inline JS |
| `style.css` | All styles |
| `README.md` | This file |

## Deploy on GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **main** branch, root (`/`)
4. Your site is live at `https://yourusername.github.io/portfolio`

## Customize

- Replace **"Your Name"**, **"Your City"**, links, and project descriptions in `index.html`
- Swap the photo placeholder with `<img src="your-photo.jpg" alt="Your Name" />`
- Add a `resume.pdf` to the root if you want the resume button to work
- Edit colors in the `:root` CSS variables in `style.css`
